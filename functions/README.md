# Backend anterior (referência histórica)

O aplicativo atual grava diretamente no Firestore, funciona no plano Spark e é publicado como site estático. Este diretório não participa do build, dos testes atuais, dos emuladores ou do deploy. Não é necessário instalar suas dependências ou implantar Functions. A configuração ativa está em `firebase.json`; o guia atual é `docs/DEPLOY.md`.
